# Car Price Prediction

A machine learning project for predicting used car selling prices using Python and Scikit-learn.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Features

The model uses:

- Year
- Present Price
- Kms Driven
- Fuel Type

## Feature Engineering

Two additional features were created:

- Car Age
- Kilometers per Year

## Machine Learning Pipeline

The project uses a Scikit-learn Pipeline containing:

1. Feature Engineering
2. Missing Value Imputation
3. Feature Scaling
4. One-Hot Encoding
5. Linear Regression

## Model Evaluation

The model is evaluated using:

- RMSE
- R² Score

## Project Files

- `Car price prediction.ipynb` — Jupyter Notebook containing the complete project
- `car data.csv` — Dataset
